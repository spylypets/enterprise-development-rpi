# Source code for [Enterprise Development with Raspberry Pi](https://leanpub.com/enterprisedevelopmentrpi) book

All example projects presented in this repository were developed with the usage of a Raspberry Pi 5 single-board computer with 8GB RAM. JavaScript code from chapter 5 was tested on a Raspberry Pi Zero W board.
So, to get a full taste of this book, we advise you to use a similar (or higher) RPi environment.
Nevertheless, all the examples can be run on any hardware with a Linux/Unix OS installed. Also, this code can be run (may be, with some minor adaptation) on the Windows platform.
